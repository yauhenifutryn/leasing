    **File 2: rag_demo_system/services/voxtral_server.py**

    Mirror whisper_server.py structure with key differences for Voxtral's audio processing:

    1. Imports: from __future__ import annotations, base64, io, os, wave, numpy as np, torch, FastAPI, HTTPException, BaseModel. Also import scipy.signal for resampling.

    2. TranscribeRequest(BaseModel): audio_b64 (str), session_id (str), language (str = "ru"), sample_rate_hz (int = 24000)

    3. VoxtralTranscriber class:
       - __init__(self, model_id: str, device: str):
         * Deferred import: from transformers import VoxtralRealtimeForConditionalGeneration, AutoProcessor
         * self._processor = AutoProcessor.from_pretrained(model_id)
         * self._model = VoxtralRealtimeForConditionalGeneration.from_pretrained(model_id, device_map=device, dtype=torch.bfloat16)
         * self._target_sr = self._processor.feature_extractor.sampling_rate  # 16000

       - transcribe_pcm16(self, audio_bytes: bytes, sample_rate_hz: int, language: str) -> str:
         * Convert raw PCM16 bytes to numpy float32 array:
           audio_int16 = np.frombuffer(audio_bytes, dtype=np.int16)
           audio_float = audio_int16.astype(np.float32) / 32768.0
         * Resample from sample_rate_hz to self._target_sr (16000) if they differ:
           if sample_rate_hz != self._target_sr:
               num_samples = int(len(audio_float) * self._target_sr / sample_rate_hz)
               audio_float = scipy.signal.resample(audio_float, num_samples)
         * Process: inputs = self._processor(audio_float, sampling_rate=self._target_sr, return_tensors="pt")
         * Move to device: inputs = inputs.to(self._model.device, dtype=self._model.dtype)
         * Generate: outputs = self._model.generate(**inputs)
         * Decode: text = self._processor.batch_decode(outputs, skip_special_tokens=True)[0]
         * Return text.strip()

    4. create_app(transcriber: VoxtralTranscriber) -> FastAPI:
       - Title: "Voxtral STT Service"
       - GET /health -> {"ok": True, "provider": "voxtral"}
       - POST /transcribe(payload: TranscribeRequest) -> decode audio_b64 (base64.b64decode), call transcriber.transcribe_pcm16(audio_bytes, payload.sample_rate_hz, payload.language), return {"ok": True, "provider": "voxtral", "session_id": payload.session_id, "text": text}

    5. create_unavailable_app(reason: str) -> FastAPI:
