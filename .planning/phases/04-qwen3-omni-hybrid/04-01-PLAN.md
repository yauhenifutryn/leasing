Create `rag_demo_system/services/qwen3_omni_server.py` following the Phase 2 sidecar pattern from `qwen3_tts_server.py` but adapted for Omni. Structure:

1. **Pydantic models:**
   - `ChatRequest(BaseModel)` with fields: `audio_b64: str`, `context_chunks: list[str]`, `system_prompt: str = ""`
   - `ChatResponse(BaseModel)` with fields: `audio_b64: str`, `text: str`, `sample_rate_hz: int = 24000`, `t_omni_first_audio: float`

2. **Model loader class `Qwen3OmniInference`:**
   - `__init__(self, model_path: str, device: str, attn_impl: str)` with deferred imports of `Qwen3OmniMoeForConditionalGeneration` and `Qwen3OmniMoeProcessor` from transformers, and `process_mm_info` from `qwen_omni_utils`
   - Load model via `Qwen3OmniMoeForConditionalGeneration.from_pretrained(model_path, dtype="auto", device_map="auto", attn_implementation=attn_impl)`
   - Load processor via `Qwen3OmniMoeProcessor.from_pretrained(model_path)`
   - `chat(self, req: ChatRequest) -> ChatResponse` method that:
     a. Writes `base64.b64decode(req.audio_b64)` to a `tempfile.NamedTemporaryFile(suffix=".wav", delete=False)` inside a try/finally that always calls `os.unlink(tmp_path)` (Pitfall 6)
     b. Builds the grounding system prompt using `SYSTEM_PROMPT_TEMPLATE` (see below) with context_chunks joined by "\n\n". If `req.system_prompt` is non-empty, use that instead.
     c. Builds conversation list: `[{"role": "system", "content": [{"type": "text", "text": system_text}]}, {"role": "user", "content": [{"type": "audio", "audio": tmp_path}]}]`
     d. Calls `self._processor.apply_chat_template(conversation, add_generation_prompt=True, tokenize=False)` to get `text_tmpl`
     e. Calls `process_mm_info(conversation, use_audio_in_video=False)` to get `(audios, images, videos)`
     f. Calls `self._processor(text=text_tmpl, audio=audios, images=images, videos=videos, return_tensors="pt", padding=True, use_audio_in_video=False)` and moves inputs to model device/dtype
     g. Calls `self._model.generate(**inputs, speaker=SPEAKER, thinker_return_dict_in_generate=True, return_audio=True, use_audio_in_video=False)` returning `(text_ids, audio_tensor)`
     h. Records `t_omni_first_audio = time.time()` immediately after generate() returns
     i. Decodes text: `self._processor.batch_decode(text_ids.sequences[:, inputs["input_ids"].shape[1]:], skip_special_tokens=True, clean_up_tokenization_spaces=False)[0]`
     j. Converts audio tensor to WAV base64: `audio_np = audio_tensor.reshape(-1).detach().cpu().numpy()`, write to BytesIO via `sf.write(buf, audio_np, samplerate=24000, format="WAV", subtype="PCM_16")`, base64 encode
     k. Returns `ChatResponse(audio_b64=..., text=answer_text, sample_rate_hz=24000, t_omni_first_audio=t_omni_first_audio)`

3. **Constants at module level:**
   - `MODEL_PATH = os.getenv("QWEN3_OMNI_MODEL_PATH", "Qwen/Qwen3-Omni-30B-A3B-Instruct")`
   - `SPEAKER = os.getenv("QWEN3_OMNI_SPEAKER", "Chelsie")`
   - `ATTN_IMPL = os.getenv("QWEN3_OMNI_ATTN_IMPL", "flash_attention_2")`
   - `SYSTEM_PROMPT_TEMPLATE` as a module-level string:
     ```
     "Вы — голосовой ассистент компании Mikro Leasing. "
     "Отвечайте СТРОГО на основе предоставленного контекста. "
     "Не используйте знания, не содержащиеся в контексте. "
     "Если информация по вопросу отсутствует в контексте, "
     "скажите: 'Извините, у меня нет информации по этому вопросу.'\n\n"
     "Контекст:\n{context_block}"
     ```

4. **App factory `create_app(inference: Qwen3OmniInference) -> FastAPI`:**
   - `GET /health` returning `{"ok": True, "provider": "qwen3_omni"}`
   - `POST /chat` calling `inference.chat(req)` and returning the ChatResponse

5. **`_build_default_app() -> FastAPI`** function (called at module level for uvicorn):
   - Instantiates `Qwen3OmniInference(MODEL_PATH, "auto", ATTN_IMPL)`
   - Calls `create_app(inference)`
   - Prints startup banner: model path, speaker, attn_impl

6. **Module-level:** `app = _build_default_app()`

Per D-05: All prompts and grounding instructions in Russian.
Per D-09: Single POST /chat endpoint with specified request/response shape.
Per D-10: GET /health endpoint.
Per Pitfall 2: No batching, one request at a time.
Per Pitfall 3: Always include system prompt with grounding instruction.
