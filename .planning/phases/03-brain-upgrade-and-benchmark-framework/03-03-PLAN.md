    **Part C: Create rag_demo_system/scripts/benchmark_runner.py**

    Async CLI script using argparse and websockets. Structure:

    ```
    benchmark_runner.py --fixture fixtures/bench_questions_ru.jsonl
                        --profile baseline
                        --output results/bench_<profile>_<timestamp>.jsonl
                        --ws-url ws://localhost:8787/ws/voice
                        --backend-url http://localhost:8787
                        [--timeout 30]
                        [--warmup 3]
    ```

    Core flow:
    1. Parse CLI arguments with argparse.
    2. Load env profile via `load_dotenv(base_env)` then `load_dotenv(profile_env, override=True)`. Read BENCH_* vars from env.
    3. Load fixture JSONL file.
    4. Create results output directory if needed.
    5. For each question in fixture:
       a. Connect to WebSocket.
       b. Send session.update with BENCH_BACKEND, BENCH_BRAIN_MODEL, BENCH_STT_PROVIDER, BENCH_TTS_PROVIDER from profile.
       c. Wait for session.updated, extract stack_id.
       d. Call POST /api/tts on the backend to synthesize the question text into base64 audio (using --backend-url + /api/tts).
       e. Record t_speech_stopped = time.time().
       f. Send input_audio_buffer.append with the base64 audio.
       g. Send input_audio_buffer.commit.
       h. Collect events until response.done:
          - From conversation.item.input_audio_transcription.completed: extract transcript
          - From response.done: extract used_knowledge, timings
       i. Extract timing fields from the response.done event's timings dict or from the voice_turn log if available.
       j. Compute keyword_hits by checking which expected_keywords appear in the answer (case-insensitive substring match).
       k. Compute keyword_hit_rate = len(hits) / len(expected_keywords) if expected_keywords else None.
       l. Flag warmup=true for the first N questions (default 3, per D-05).
       m. Write the result as a JSON line to the output file.
    6. On error (timeout, disconnect per D-06): set error field, set all timings to null, continue to next question.
    7. Use a fresh WebSocket connection per question to avoid session state contamination (per Pitfall 2).
    8. Use `json.dumps(result, ensure_ascii=False)` for all JSONL output (per Pitfall 4).
    9. Print summary at the end: total questions, errors, average primary_kpi_ms for non-warmup.

    IMPORTANT: The runner is synchronous-per-question (await one response.done before next question). Do NOT parallelize questions within a run.

    IMPORTANT: The runner must send session.update FIRST, wait for session.updated, THEN send audio (per Pitfall 5). This ensures the correct stack_id.

    IMPORTANT: The timing fields in the JSONL output should come from the backend's voice_turn log event if accessible. If not (timings are in the response.done event), use those. The runner also records its own t_speech_stopped as the moment it sends input_audio_buffer.commit.

    The `compute_keyword_hits` function and `build_result_dict` helper should be importable for unit testing.

    **Part B: Create rag_demo_system/scripts/benchmark_compare.py**

    CLI script that reads two JSONL result files and outputs a side-by-side markdown table per D-07 and D-08.

    ```
    benchmark_compare.py results_a.jsonl results_b.jsonl [--output comparison.md]
    ```

    Implementation:

    1. `load_results(path: Path) -> list[dict]`: Read JSONL file, return list of dicts. Filter out warmup=true rows (per D-05).

    2. `percentiles(values: list[float | None]) -> dict`: Compute mean/p50/p95 using `statistics.mean` and `statistics.quantiles(data, n=100, method='inclusive')`. Return {"mean": float|None, "p50": float|None, "p95": float|None}. Handle empty/all-None lists gracefully (return all None).
       ```python
       import statistics

       def percentiles(values):
           clean = [v for v in values if v is not None]
           if not clean:
               return {"mean": None, "p50": None, "p95": None}
           qs = statistics.quantiles(clean, n=100, method="inclusive")
           return {
               "mean": statistics.mean(clean),
               "p50": qs[49],
               "p95": qs[94],
           }
       ```

    3. `compute_metrics(results: list[dict]) -> dict`: From a list of non-warmup results, compute:
       - primary_kpi_ms: percentiles of [r["primary_kpi_ms"] for r in results if r["error"] is None]
       - llm_ttfb_ms: percentiles of [r["llm_ttfb_ms"] for r in results if r["error"] is None]
       - keyword_hit_rate: mean of [r["keyword_hit_rate"] for r in results if r["keyword_hit_rate"] is not None]
       - error_count: count of results where r["error"] is not None
       - total_questions: len(results)

    4. `format_comparison_table(metrics_a: dict, metrics_b: dict, label_a: str, label_b: str) -> str`:
       Build the markdown table. Columns: Metric, Stack A, Stack B, Delta, Winner.
       Rows:
       - Primary KPI mean (ms)
       - Primary KPI p50 (ms)
       - Primary KPI p95 (ms)
       - LLM TTFB mean (ms)
       - LLM TTFB p50 (ms)
       - LLM TTFB p95 (ms)
       - Keyword hit rate
       - Error count
       - Total questions

       For latency metrics: lower is better, winner arrow points to lower value.
       For keyword hit rate: higher is better, winner arrow points to higher value.
       For error count: lower is better.

       Winner format per D-08: "<-- A" or "B -->" (arrow pointing to the winning stack).

       Delta format: show the difference (B value - A value). Negative means B is better for latency metrics.

       Format numbers to 1 decimal place for ms, 2 decimal places for rates.

       ```python
       parser = argparse.ArgumentParser(description="Compare two benchmark JSONL result files")
       parser.add_argument("file_a", type=Path, help="First result JSONL file")
       parser.add_argument("file_b", type=Path, help="Second result JSONL file")
       parser.add_argument("--output", "-o", type=Path, default=None, help="Output markdown file (default: stdout)")
       ```

    6. Main function: load both files, compute metrics, format table, write to output or stdout.
