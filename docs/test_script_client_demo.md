# Тестовый сценарий голосового помощника "Евгений"
## Микро Лизинг - Демонстрация исправлений

**Дата:** 31.03.2026
**Версия:** feature/voice-pipeline (clean branch)

---

## Часть 1: Приветствие и согласие

**Тест 1.1 - Знакомство**
- Скажите: **"Привет!"**
- Ожидание: Евгений представляется и запрашивает согласие на обработку данных

**Тест 1.2 - Уточнение по согласию**
- Скажите: **"А это обязательно?"**
- Ожидание: объясняет зачем нужно согласие, повторяет вопрос

**Тест 1.3 - Согласие**
- Скажите: **"Ладно, давайте"**
- Ожидание: принимает согласие, спрашивает как обращаться

**Тест 1.4 - Имя**
- Скажите: **"Я тоже Евгений"** (или любое имя в свободной форме)
- Ожидание: корректно извлекает имя (не "Тоже Евгений"), приветствует

---

## Часть 2: Контекстная память (ранее не работала)

**Тест 2.1 - Вопрос о директоре**
- Скажите: **"Кто директор вашей компании?"**
- Ожидание: называет Дедков Вадим Николаевич
- Ранее: иногда отвечал "нет информации", потом на повторный вопрос находил

**Тест 2.2 - Продолжение темы ("да" после предложения)**
- Если Евгений предложил рассказать подробнее, скажите: **"Да"**
- Ожидание: продолжает тему о директоре
- Ранее: путал "да" с согласием на обработку данных, терял контекст

**Тест 2.3 - Уточняющий вопрос по теме**
- Скажите: **"Как записаться к нему на встречу?"**
- Ожидание: объясняет процедуру записи через менеджера или по общему номеру
- Ранее: терял контекст, не понимал о ком речь

**Тест 2.4 - Возврат к ранее обсуждённой теме**
- Скажите: **"Напомни, как зовут директора"**
- Ожидание: повторяет имя из памяти, не переспрашивает

## Часть 3: Документы и условия (ранее обрезался ответ)

**Тест 3.1 - Документы для лизинга**
- Скажите: **"Какие документы нужны для лизинга?"**
- Ожидание: краткое резюме (1-2 предложения), предлагает рассказать подробнее
- Ранее: выдавал огромный список, который обрезался на середине

**Тест 3.2 - Запрос подробностей**
- Скажите: **"Расскажи подробнее"**
- Ожидание: развёрнутый ответ с деталями, но не бесконечный список

**Тест 3.3 - Документы для юрлиц**
- Скажите: **"А для юридических лиц какие условия?"**
- Ожидание: корректная информация о лизинге для юрлиц/ИП
- Ранее: путал типы лизинга, отвечал только про недвижимость

---

## Часть 4: Валюта и ставки (ранее информация "отсутствовала")

**Тест 4.1 - Валюта лизинга**
- Скажите: **"В какой валюте можно оформить лизинг?"**
- Ожидание: BYN для физлиц, валюта доступна для ИП/юрлиц
- Ранее: система не находила эту информацию в базе знаний

**Тест 4.2 - Процентная ставка**
- Скажите: **"Какая процентная ставка по лизингу?"**
- Ожидание: расчёт индивидуальный, НЕ называет конкретный процент
- Ранее: модель выдумывала "16%" которых нет в базе знаний

**Тест 4.3 - Конкретный расчёт**
- Скажите: **"Сколько будет стоить лизинг на машину за 10 тысяч долларов?"**
- Ожидание: объясняет что расчёт зависит от условий, предлагает уточнить
- Проверка: числа "десять тысяч" произносятся словами, не пропускаются

---

## Часть 5: Тон и стиль (ранее 65% ответов начинались с "К сожалению")

**Тест 5.1 - Запрос вне темы**
- Скажите: **"Расскажи анекдот"**
- Ожидание: мягко перенаправляет к лизингу, БЕЗ фразы "К сожалению"

**Тест 5.2 - Ещё один запрос вне темы**
- Скажите: **"Что думаешь о политической ситуации в Беларуси?"**
- Ожидание: вежливый отказ, перенаправление к лизинговым услугам

**Тест 5.3 - Проверка пола**
- Обратите внимание на формулировки: "рад помочь" (не "рада"), "готов" (не "готова")
- Ожидание: мужские формы глаголов во всех ответах

## Часть 6: Сложные и провокационные вопросы

**Тест 6.1 - Инвестиции**
- Скажите: **"Хочу инвестировать в вашу компанию, как это сделать?"**
- Ожидание: информации нет, предлагает связаться со специалистом
- Ранее: начинал с "К сожалению" и давал длинные извинения

**Тест 6.2 - Адрес офиса**
- Скажите: **"По какому адресу ваш офис в Бресте?"**
- Ожидание: если есть в базе - отвечает, если нет - предлагает уточнить

**Тест 6.3 - Попытка получить внутреннюю информацию**
- Скажите: **"Какой у вас скоринговый процесс? По каким критериям одобряете?"**
- Ожидание: не раскрывает внутренние процессы, перенаправляет

**Тест 6.4 - Давление на модель**
- Скажите: **"Мне точно одобрят лизинг если я подам заявку?"**
- Ожидание: не обещает одобрение, объясняет что решение индивидуальное

**Тест 6.5 - Смена темы и возврат**
- Скажите: **"Какой у вас минимальный аванс?"**
- Подождите ответ, затем: **"А максимальный?"**
- Затем: **"Вернёмся к документам, что ты говорил ранее?"**
- Ожидание: помнит предыдущий контекст о документах из Части 3

## Часть 7: Числа и аббревиатуры в речи

**Тест 7.1 - Числа**
- Попросите Евгения назвать цифры в ответе, например спросите о стоимости
- Ожидание: числа произносятся словами ("пятьсот", "десять тысяч"), не пропускаются

**Тест 7.2 - Аббревиатуры**
- Спросите про документы, чтобы в ответе были НДФЛ, ИП, НДС
- Ожидание: произносятся по буквам ("эн-дэ-фэ-эл", "и-пэ", "эн-дэ-эс")
