# CTranslate2 (used by faster-whisper) PTX compatibility:
# All recent CTranslate2 pip wheels are compiled with CUDA 12.8 (PTX ISA 8.7),
# which requires NVIDIA driver >= 570. Servers with driver 550 (PTX ISA 8.4)
# get cudaErrorUnsupportedPtxVersion on H100 (sm_90, no native SASS in wheel).
#
# Workaround: provision_server.sh detects driver < 570 and sets WHISPER_DEVICE=cpu.
# CPU Whisper (int8, large-v3) runs at ~2-3s per utterance on Xeon, acceptable
# for voice assistant use. GPU Whisper requires driver 570+ or building CTranslate2
# from source with CUDA 12.4 targeting sm_90.
